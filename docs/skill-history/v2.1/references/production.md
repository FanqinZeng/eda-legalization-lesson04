# 制作约定

## 先后顺序

1. 核对主题与固定上游提交，建立范围、来源、手算样例及反例。
2. 写课程设计和计划；先执行下方适用的前置检查，再验证纯 JS 引擎和独立 Python 参考。
3. 建完整双语网页、实验、练习、资料页和 Worker Python。
4. 使用引擎导出数据，写双语旁白与语义对齐表；先看实帧和真实样片，再合成全片。
5. 验收网页和影片，依据观察修正试点和 skill；冻结迁移版。
6. 后续课消费迁移版，完整制作一次；验收、修复实际错误、发布。

## 迁移后的前置检查

把适用的夹具写进引擎或真实浏览器检查，在制作完整页面、导出影片数据之前运行。以下是第二课实际失误提炼出的约定；没有对应几何、坐标或表单功能的课程不套用这些夹具。

| 适用功能 | 实现约定 | 最小可观察验收 |
| --- | --- | --- |
| 小数坐标的键盘和拖动 | 模型保留原始精度；仅对操作轴加位移。拖动从pointerdown的坐标与原始位置计算delta，按交互步长量化delta，再加回原点。显示格式化独立于模型。 | 从(2.45,1.04)水平右移0.1得到(2.55,1.04)，水平拖动0.5得到(2.95,1.04)；非操作轴不变，最近行等派生结果不应因另一轴被舍入而改变。 |
| 矩形重叠及合法性 | 按来源和课程声明定义边界。若约定严格正面积，则dx>0且dy>0才重叠；site/row对齐容差单独命名和使用。若模型另有间距或几何容差，明确其含义和单位。 | 检查恰好接触、极小正交叠和极小间隙；对宽1的相邻单元，把后者x从2改为1.9999999995，仍须检出交叠。JS与独立Python验证输入/中间状态，不只验证最终已取整结果。 |
| 表单重绘、语言切换和反馈 | 输入草稿、有效模型值与诊断采用一致策略：保留无效草稿时保留对应标记并翻译提示；恢复有效值时同步移除错误标记与过期提示。动态表头、目标值、fixed标签和错误反馈都随语言更新。 | 连续编辑两个字段；无效输入→切语言→再编辑/重置；确认可见值、aria-invalid和当前语言提示一致。重绘、答题提交后继续Tab/方向键，焦点仍在合理控件。 |
| Python与媒体素材生成器 | 正式生成命令只读取本仓库提交的源或明确锁定且可取得的依赖。复用模板随仓库提交；生成脚本的输出归属明确，保留已修复的Worker生命周期等手写控制器。 | 无兄弟仓库的独立临时副本中运行生成器；应成功、输出可复现，未负责生成的HTML/controller/CSS/Worker字节不变。生成后运行资料一致性和git diff检查，不能借本机恰好存在的旧课掩盖依赖。 |

矩形夹具只说明严格正面积模型，不能把这个判定强加到另有容差的课程。极小的非零面积、位移或需求使用科学计数或显式精度提示，不能在诊断中显示为0后给出相反的合法性结论。

把上述断言列入首次实现时的验收输入，而非只在最后总验收抽查。若生成器重建源码/示例，重跑站内Python和阅读页一致性；若引擎结果改变，重新导出影片数据，核对受影响分镜、旁白与精确值，再按实际变化重渲染相关影片。未受影响的标准夹具和媒体可以复用，记录判断依据。

## 建议文件组织

`site/` 包含可直接发布的主页、assets、reading、python、downloads、media 和按需运行时；`src/` 或 `site/assets/` 保存无 DOM 引擎；`video/` 保存双语分镜、导出数据、语义对齐、冻结音频、时间轴和许可字体；`scripts/` 保存可复现制作与验收命令；`tests/` 保存有教学意义的数学和行为检查；`docs/qa/` 记录实际结果。

`PROGRESS.md` 必须有当前阶段、下一步、已验收证据、真实限制及线上提交。`docs/skill-iteration.md` 对试点记录 skill 修改的实际原因。后续课记消费版本、SHA256及消费副本路径。更新当前skill时，把已消费版本保存在不可改写的历史目录，并让核对脚本验证该目录；不得把旧课程的消费版本改成新版本。不把计划写成验收结果。

## 范围与自主推进

单课制作以用户链接到的 module 为边界。不要把整站 playbook 的章数、片数、字数、PPTX 配额当作新任务额外要求。优先完成教学闭环。已经明确要求发布且目标仓库清楚时，例行设计、依赖、实现、测试、普通提交、推送与 Pages 配置属于执行范围；不得因此重新等待用户批准设计。

## 可复用基线

在当前工作区，`eda-placement-lesson3/` 是最近完成的参考实现：语言与影片联动、站内阅读页、本地 Pyodide、Worker 停止/超时、双语字幕和媒体验证都可参考。复制通用组件时检查许可并去掉线长模型、课名、数值、缓存、学习进度键和过期部署声明。

`Partitioning_Module_Coordinator/` 提供动画配色与更早制作经验，只读参考，除用户额外授权不得改变其内容或定时任务。
