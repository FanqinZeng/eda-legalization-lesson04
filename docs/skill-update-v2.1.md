# skill v2.1.0

用户要求将第二课验收中的实际问题用于后续一次完整制作。当前skills/eda-lesson-studio为v2.1.0，新增规则在references/production.md的“迁移后的前置检查”，入口要求在编写交互、数值判定和生成脚本之前执行。

| 实际问题 | 后续首次制作时采用的做法 |
| --- | --- |
| 小数键盘或拖动把未操作轴一起舍入，改变最近行 | 保留模型精度；仅操作轴加delta；拖动量化位移再加回原点；先用非步长对齐的小数夹具验证。 |
| 全局epsilon漏掉严格正面积交叠 | 按模型声明分离对齐容差与重叠定义；同时验证恰好接触、微小正交叠、微小间隙，以及原始/中间布局的JS与独立Python。 |
| 无效值被恢复后仍留旧语言错误；动态表头或答题焦点遗漏 | 值、错误标记与双语提示采用一致策略；检查连续编辑、切语言、重置、动态标签和提交后继续键盘。 |
| 生成器隐含读取兄弟仓库，可能覆盖手写Worker修复 | 正式生成器只读本课源或可取得的锁定依赖；在无兄弟目录的副本再生，确认未归属输出的控制器字节不变。 |

极小非零值采用科学计数或精度提示；引擎修复后重新核对派生Python/在线资料/影片数据，仅按实际内容变化重渲染。
