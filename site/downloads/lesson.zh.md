# 对齐了，还不一定合法：Greedy Site/Row Snap

## 本课解决什么，保留什么问题

输入是cell左下角的浮点坐标、各自宽度、芯片尺寸、site与row网格，以及固定宏约束。输出是吸附后的坐标。目标是让每个cell对齐site和row并满足边界，算法不会为邻居保留空间，因此不保证非重叠。

学习后应能手算x取整、宽度钳制与最近row，解释half-tie、fixed宏、全体和movable位移，并使用cell中心求HPWL。完成后要能说清楚“snap”和“legal”之间少了哪项条件，而不是只会按按钮。

## 坐标与网格约定

本课siteW=1，chip宽W=12、高H=6；rowH=2，行底rows=[0,2,4]。每个cell高度等于rowH，宽度从数据读取。坐标是左下角，矩形占用[x,x+w]与[y,y+rowH]。

图中y向上。浮点输入可能跨行、越过边界或偏离fixed锁定位置，这正是诊断内容。图形按照真实宽度和行高绘制，不能把cell都当成点来检查重叠。

## 核心循环与终止

每个cell只处理一次。movable单元的x先取最近整数，再限制到[0,W-w]；y选择rows中距离最近的一行。fixed宏恢复约束里明确给出的坐标。处理完所有cell即终止，不会循环搜索空位。

```text
for cell in cells:
    if fixed(cell):
        output[cell] = locked_position[cell]
    else:
        x = clamp(round_even(input.x), 0, W - width[cell])
        y = first_argmin(rows, abs(row - input.y))
        output[cell] = (x,y)
# No overlap search or row packing occurs here.
```

## 教师浮点黄金例

```text
Cell  width   before        after    L1
A       2     (3.7,1.2)     (4,2)    1.1
B       2     (4.1,1.4)     (4,2)    0.7
C       2     (5.2,2.3)     (5,2)    0.5
D       2     (8.4,3.8)     (8,4)    0.6  fixed constraint
E       1     (0.3,4.6)     (0,4)    0.9
F       1     (10.2,0.4)    (10,0)   0.6
```

A到row2的距离是0.8，小于到row0的1.2；B也选择row2。它们的x都吸到4。C吸到5，宽度2意味着它与A、B都相交。六个cell的site、row、边界和fixed检查都可以通过，非重叠仍不通过。

## 等距与跨语言复现

Python round在半整数处取最近偶数：0.5→0，1.5→2，2.5→2，3.5→4。JavaScript Math.round(2.5)给3；不能直接说两个上游实现对所有边界都一致。本站JS显式实现Python取偶规则，并由独立Python交叉检查。

最近行的等距规则与x取整是两件事。我们沿用rows列表先出现者，所以y=1在[0,2,4]中选择0，y=3选择2。如果把rows重排，等距答案可能变；本课默认列表按升序固定。测试2.5和3.5不能用随机浮点例子替代，因为随机数几乎碰不到恰好一半。

## 边界必须看到整个cell

宽W的芯片，宽w的cell，其左下角最多到W-w，而不是W。边界情境使用W=6、w=2，输入B.x=5.7先取整6，再钳制到4；最终区间[4,6]恰好留在芯片中。

负x也先取整再钳制到0。合法行底由数据提供，并必须保证row+rowH不超过H。算法不能靠只检查左下角在芯片内部来证明整个矩形合法。

## 为什么仍有三对重叠

完整结果中，A和B都占据x区间[4,6]、y区间[2,4]；C占据[5,7]×[2,4]。A/B相交面积4，A/C与B/C各2。重叠对数是3；这些是成对面积，不把面积相加误称为唯一覆盖的重叠总面积。

两个矩形只有x和y方向都存在正长度交叠，才算正面积重叠。宽1的A放在(1,0)，B在(2,0)，边缘接触但没有正面积相交，应允许。源码的已对齐同row场景与我们的二维矩形检查结果一致；浮点输入时额外展示完整二维重叠，帮助理解跨行情况。

## fixed宏D与两个位移口径

教师数据的fixed约束是D=(8,4)，但starter_float原始坐标给D=(8.4,3.8)。greedy snap按锁定约束恢复D，并没有把D作为movable进行优化。恢复距离为|8-8.4|+|4-3.8|=0.6。

上游total_displacement统计所有cell，即使参数名带fixed也不会排除它们。因此全体L1=1.1+0.7+0.5+0.6+0.9+0.6=4.4；只统计movable时排除D，得到3.8。本站并列显示两个定义，读报告前先确认计数范围。

## HPWL使用中心，也不证明合法

cell中心是(x+w/2,y+rowH/2)。每个net的HPWL是中心横坐标极差加纵坐标极差，六个net单位权重各计一次。吸附后六项分别是0、5、1、6、6、14，总和32。

浮点输入的总HPWL是36，吸附后降到32，但仍有3对重叠。线长改善不意味着合法；同样，较小位移也不能代替row/site/fixed/bounds/non-overlap检查。混合宽度时，左下角距离与中心距离可能不同，不可沿用点pin模型而忽略w/2。

## 复杂度与后续课程

核心snap对n个cell扫描r个候选行，时间O(nr)，输出O(n)。本教学实现为逐步重放保存每个前缀快照，额外O(n²)存储与复制；完整矩形重叠诊断O(n²)，HPWL还需遍历net成员。不能把核心循环的复杂度当作整套教学界面的全部开销。

后续需要overlap removal、row packing或Abacus等方法才能处理碰撞。本课不实现这些求解器，不将它们的输出偷偷称作greedy snap的结果。先准确说明当前失败的检查项，再选择下一步工具。
