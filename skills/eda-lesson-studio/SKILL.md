# EDA lesson studio

把一个明确主题教清楚，并交付网页和实际成片。先读 [制作约定](references/production.md)，需要改动媒体流水线时再读 [媒体实现](references/media.md)。历史经验的出处见 [证据](references/evidence.md)。

## 开始

读取当前用户要求、目标仓库、适用 AGENTS.md、PROGRESS.md 和已有文件。核对远端仓库身份、分支、当前修改、登录及 Pages 权限。用户已明确授权的目标仓库写入和发布不重复请求确认；遇到缺凭据或真实权限阻塞才立即说明具体操作。其他任务的仓库或分支限制只适用于它们原来的任务，不能移植为本任务的禁令。

根据用户给定的课程目录确定主题，issue 编号只用于归属核对；不要凭编号猜内容。固定上游提交，读 README、讲稿、例子、检查清单、实现和测验，区别原作者主张、已验证事实、自己的设计与重建。发现上游错误先修正并记录，不把错误动画化。

模块引用的 common 求解器、坐标工具和测试也是源材料。明确单位、坐标参考、固定对象的计数范围及舍入/tie规则；Python round 与 JS Math.round 不等价。随机对照之外必须加入半整数、恰好相等、零长和同格等适用边界。比较两个模型之前对齐量纲和总量，修正与源码兼容模式要明确区分。

已给出明确交付、参考和自主推进要求时，写简洁设计与实施计划后执行。不要用反复调研、重复确认设计或机械等待定时触发来代替制作。参考网站提取具体教学优点并注明出处，不照搬整站或无授权素材。

## 单课交付

- 中文 / English 覆盖导航、正文、实验反馈、题目、资料和 Python 页。支持直接语言链接，切换语言保留学习状态；存储禁用时仍可学习。
- 清晰学习路径：问题和目标、讲解、影片、实算实验、反例、带解析练习、在线资料、Python 实践、来源。篇幅服务于主题，不强制套用整套八章课程或四类影片的体量。
- 一个纯算法引擎产生可检查的步骤记录。网页、题目、图表和影片数值共用该数据；另写独立 Python 参考，用手算、反例及不变量交叉验证。
- 真正可操作的实验，能编辑输入、重置、单步和查看中间值。拖动提供键盘或表单等价操作。动画表示算法过程，不能用预制数字冒充计算。
- 真正 CPython 的浏览器 Python 交互台，能编辑和执行代码、显示输出与异常、停止和超时恢复。提供练习、参考、可复现样例。运行时放在 Worker 中；不得以代码高亮或模拟输出冒充运行。
- 中文和英文各一部完整旁白动画 MP4；画面文字也分别本地化。1080p / 30fps 是已有作品的基准，需流畅展示本课机制和真实步骤。不能交静态幻灯片轮播、浏览器朗读或仅有字幕的无配音视频。
- 每个配音版本都提供同屏双语字幕、单语字幕、章节、封面、全文文字稿和可复现分镜、渲染源。字幕按语义对齐，不能机械按句子序号拼接。
- 讲义、代码、样例、文字稿和复现说明能直接在网页阅读与复制；下载是补充选项。
- 静态网页用相对路径，适配 GitHub Pages 项目子路径；手机、键盘、减少动态和无存储环境均可使用。初次加载仅按需载入视频和 Python 大文件。

## 网站与影片一致

默认界面语言决定影片画面、配音、字幕和文字稿。订阅后续语言变化；手动切换配音也必须可用。跨语言切片按语义章节映射播放位置，保留倍速、字幕偏好和合理的暂停状态。必须实际验证 `?lang=en` 初始载入的是英文画面及英文音轨。

阅读区清楚、留白充分；影片和实验用深蓝绿、象牙文字、青绿及暖金。遵循用户提供的参考，保持字体与图形克制。色彩之外也有标签和线型。影片每一段有不同的教学动作：路径展开、概率分配、比较、状态迁移、反例或实验回扣；不要反复平移同一幅图凑时长。

先制作简短真实样片并观察代表帧，解决图形、字幕、旁白节奏后再渲染全文。语音的实际时长决定分镜与字幕时间，缓存冻结音频。旁白解释画面正在发生的事，公式一次引入一项。底部字幕区与算法图区分离。

实帧检查必须包含最长文字、循环小数、多对象身份和单步状态：显式换行先拆分再绘制，格子和字幕按真实字体测宽；必要舍入要标明，旁白和精确值保持一致。原始对象名取自输入，虚拟中心/对象另有身份；不要从轨迹的首末位置猜标签。展示某一步时只画该步贡献，展示合计时明确是合计。动画动作随教学状态变化，不靠重复相机平移填充时间。

手机保留影片章节、实验和代码等学习能力，不能靠隐藏功能满足无横向溢出。影片语言进度优先按稳定语义scene id映射；时长、文字稿和章节从真实时间轴生成，避免复制上课的硬编码声明。

首访两种语言都按需载入影片：初始化src/poster/字幕/章节时不要调用主动切片的load路径，并实际检查点击前的网络请求。表单和SVG重算必须保留连续键盘操作的焦点；题目中的精确小数阈值必须可输入，成功校验后清除旧提示。若pagehide终止Python Worker，BFCache的persisted pageshow必须重建解释器；测试真正“离开后浏览器返回，再执行”。

单位未对齐时，除了文字声明，也要停用无意义的热点计数、阈值边框或差值，不能一边提醒不能比较，一边继续显示比较结论。引导按钮须选择文字所承诺的预设与约定；自由实验可以保留用户偏好。

## 打磨与迁移

试点课必须先完成真实网页和真实成片，再用观察到的问题修订 skill。每次记录：版本、实际缺陷、证据、修复、验证结果、可泛化规则。只把可迁移的经验写进 skill，课程题目与数值留在课程资料中。

试点至少经过一次完整网页学习路径和一次真实媒体检查，解决发现的问题再定稿。后续课从冻结的 skill 版本一次完成设计、引擎、网页、影片和发布；只做必要的正确性修复与验收，不重新发起相同的风格探索。记录消费的 skill 版本和散列，证明迁移确实发生。

v2的试点证据、已运行的通用媒体/网页组件和一次迁移用法见 [试点与迁移](references/pilot-transfer.md)。初始v1快照不可覆盖；冻结版的所有文件都计算散列，后续课保留消费副本。

## 验收与发布

按修改运行必要检查，不把调研当产品测试。数值检查覆盖手算例、退化输入、边界、顺序或平移等适用不变量，以及 JS / 独立 Python 对照。网页检查覆盖真实实验操作、题目反馈、全站两种语言、语言与影片联动、实际 Python 执行、异常、停止、超时、手机宽度和资源路径。

媒体检查必须针对实际 MP4：可解码 H.264 / AAC、真实非静音音轨、时长、代表帧、字幕时序与阅读时间、章节跳转、双语字幕轨及资源大小。若未完整人工试听或未测真实触屏，明确记录限制，不把自动检查写成已人工验收。

保留源码、讲稿、分镜、冻结音频、字体许可和第三方来源。不要把来源不明的音乐放进仓库；可以不配背景音乐。正常提交和快进推送到已授权仓库，不修改参考仓库或代发 issue 评论。

启用 GitHub Pages，检查对应提交的 Actions 部署成功；再检查公开 HTTPS 页面、JS/CSS、两种视频、VTT、Python 运行时及站内链接。预期 URL、推送成功和工作流排队均不能写成已发布。遇到部署仍在运行就在本轮继续检查。

定时执行必须制作实质成果并接续检查点，避免重做调研或每次重渲染未变媒体。保持 PROGRESS.md、交付说明、媒体清单与线上版本一致。完成全部已授权交付后结束该制作定时任务；截止时仍未完成则保留成果并如实报告，不改写为完成。
